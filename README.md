# Robot Arm Microcontroller Project

This repository contains a **robot arm control project** developed as part of my academic work in robotics and embedded systems.

The project focuses on **microcontroller-based control**, including GPIO control, signal generation, and peripheral interfacing, which are essential components for robotic arm actuation and sensing.

---

## Repository Structure

- **Mic_MP45DT02_ver2_Cplusplus/**  
  Source code related to sensor interfacing and signal processing using C/C++.

- **Pulse_GPIO_set_reset_v3/**  
  Microcontroller code for GPIO pulse generation and control logic.

- **MICROCONTROLLER PROJECT REPORT_*.pdf**  
  A **complete technical report** describing:
  - System architecture
  - Hardware design
  - Microcontroller configuration
  - Software implementation
  - Experimental results and analysis

- **MICROCONTROLLER PROJECT PRESENTATION_*.pdf**  
  Project presentation slides summarizing the design and results.
